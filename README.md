# Amazon KDP Puzzle Books

AI-assisted production system for researching, creating, validating, and publishing Amazon KDP puzzle/activity books.

## Core principle

AI accelerates ideation, instructions, editing, metadata, and production support. Puzzle correctness should be validated independently before publication.

## Workflow

1. Research a specific audience + puzzle type + theme.
2. Validate competition and demand.
3. Define product specifications.
4. Generate puzzle source data.
5. Validate every puzzle and answer.
6. Render the interior.
7. Proof the complete PDF.
8. Create cover and metadata.
9. Upload and check the KDP preview.
10. Track results and improve the next book.

See `research/`, `prompts/`, `validation/`, `templates/`, and `workflows/` for the system.

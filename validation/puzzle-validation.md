# Puzzle Validation Checklist

## Every puzzle
- [ ] Required entries/items exist.
- [ ] Every answer is present.
- [ ] No required answer is missing.
- [ ] No invalid characters.
- [ ] Dimensions match specification.
- [ ] Difficulty matches audience.
- [ ] Duplicate entries handled correctly.
- [ ] Answer key corresponds exactly.
- [ ] Numbering/navigation is correct.

## Word search
- [ ] Every target word can be located.
- [ ] Coordinates/directions recorded before rendering.
- [ ] No answer goes outside the grid.
- [ ] Displayed word list exactly matches validated data.
- [ ] Answer highlights match recorded coordinates.

## Visual proof
Inspect the rendered interior for clipping, tiny text, alignment, page breaks, answer visibility, duplicates, blank pages, and readability.

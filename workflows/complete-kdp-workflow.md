# Complete AI-Assisted Puzzle Book Workflow

## 1. Research
Choose a narrow customer + puzzle + theme combination. Research multiple competing books.

## 2. Product specification
Define audience, puzzle type, theme, difficulty, page count, trim size, answer format, and differentiation.

## 3. Generation
Use deterministic/programmatic generation for puzzles whenever possible. Use AI for ideation, instructions, thematic lists, editing, metadata drafts, and cover concepts.

Keep source data separate from rendered pages.

## 4. Validation
Generate puzzle data, record placements/answers, validate every answer, then generate the answer key from the same source data.

Never recreate answers from memory.

## 5. Rendering
Render pages from validated data with consistent typography, spacing, margins, numbering, and answer references.

## 6. Proofing
Inspect the complete PDF page by page for clipping, tiny text, missing answers, duplicate pages, broken symbols, awkward page breaks, and numbering errors.

## 7. Cover and metadata
Create the cover brief after the product specification is finalized. Prepare metadata from the finished product.

## 8. KDP upload
Upload interior and cover, run KDP preview, resolve issues, and inspect a physical proof when appropriate.

## 9. Portfolio learning
Track publication date, niche, format, price, sales, page reads where applicable, advertising spend, reviews, and production time.

# KDP Publishing Checklist

## Research
- [ ] Audience identified
- [ ] Competition researched
- [ ] Differentiation documented
- [ ] Production time/cost estimated

## Interior
- [ ] Trim size correct
- [ ] Margins safe
- [ ] Typography consistent
- [ ] Puzzles validated
- [ ] Answers validated
- [ ] Complete PDF proofed

## Cover
- [ ] Dimensions correct
- [ ] Title readable at thumbnail size
- [ ] Audience clear
- [ ] No clipping

## Metadata
- [ ] Title
- [ ] Subtitle
- [ ] Description
- [ ] Keywords
- [ ] Categories
- [ ] Audience/age information where applicable

## Final
- [ ] Interior uploaded
- [ ] Cover uploaded
- [ ] KDP preview checked
- [ ] Warnings/errors resolved
- [ ] Proof inspected when appropriate
- [ ] Final listing information recorded
